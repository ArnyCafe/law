# 勞動法典（iPad 版）：勞基法法典・團體協約法典

可以「寫在上面」的電子法典。專為 iPad（Safari / 加入主畫面）設計，也可在電腦、手機瀏覽器使用；第一次開啟後可離線使用。

| 法典 | 網址（部署後） | 內容 |
| --- | --- | --- |
| 勞基法法典 | `/` | 勞動基準法全 98 條、大法官解釋、判決、函釋、24 次修法對照 |
| 團體協約法典 | `/cba/` | 團體協約法全 34 條、判決・不當勞動行為裁決・函釋、4 次公布之新舊條文對照（含 97 年全文修正條次對應）、工會法・勞資爭議處理法等相關條文小字 |

兩部法典共用同一套程式（`app.js`、`app.css`），由各自的資料檔決定內容；個人註記分開儲存、分開備份。

## 團體協約法典的特色

| 功能 | 說明 |
| --- | --- |
| 紅色小字註記（上方／下方） | 長按選取條文文字 →「加註」，註記以小字顯示在那段文字的**正上方或正下方**（可選紅、深藍、綠、紫，或「接在文字後」）；該行行距自動撐開，不會蓋到條文 |
| 點一下隱藏／顯示 | 用 **Apple Pencil 或手指**點一下註記（或畫底線的文字）即隱藏，只留小小的「註」字；再點一下就顯示。設定可改為「僅 Pencil」或「僅手指」。長按註記可編輯／刪除 |
| 全部隱藏 | 上方紅色「註」鈕一鍵隱藏全部註記（背誦、自我測驗用），點「註」字可暫時打開單則；每條右上角的眼睛鈕切換該條 |
| 塗鴉模式也能切換 | 塗鴉模式中用手指點註記，或用 Pencil 輕點註記，仍可隱藏／顯示（輕點不會留下墨點） |
| 引用條文小字 | 條文中的「第○條」「前條」（藍字）及工會法、勞資爭議處理法、民法、勞基法等其他法律（綠字）點一下，即在下一行以小字顯示被引用條文，指定的項／款以黃底標示；可設定「全部展開」 |
| 相關法條 | 條文雖未明文引用、但實務上相關的他法條文（如第 6 條 ↔ 工會法第 35 條、勞資爭議處理法第 53 條），列在條文下方，點選展開小字 |
| 編按 | 主管機關改制（勞委會→勞動部、人事行政局→人事行政總處）、第 6 條第 5 項增訂、施行日期等，依全國法規資料庫沿革以小字標於條文上方，也可點選隱藏 |
| 新舊條文對照 | 19 年制定、97 年全文修正（31→34 條，附新舊條次對應）、103 年修正第 6 條、104 年修正第 5 條 |
| 判解函釋 | 最高法院、最高行政法院判決，不當勞動行為裁決，勞動部函釋，依條號歸類；要旨均為判決原文摘錄並附原文連結 |

## 功能

| 功能 | 說明 |
| --- | --- |
| 現行條文 | 全 98 條（113.07.31 修正），依章節排列；條文中引用的「第○條」可直接點選跳轉 |
| 螢光筆／底線 | 在條文上長按選取文字 → 黃、綠、藍、粉紅螢光或紅色底線，✕ 清除 |
| 條文小字註記 | 選取條文文字按「加註」，註記以小字（紅／深藍／綠／紫）直接顯示在該段文字後面，原文加同色底線；點註記可編輯、換色或刪除 |
| 註記本 | 每條一個文字註記本，自動儲存，顯示在條文下方 |
| Apple Pencil 塗鴉 | 按上方「塗鴉」鈕，用 Pencil 直接在條文上圈選、畫線、打箭頭（紅、深藍、黑、綠、螢光黃，粗細、橡皮擦、復原）；筆跡固定在所畫的文字上，改字級或轉橫直向都會跟著文字移動 |
| 手寫筆記 | 每條一張手寫紙，支援 Apple Pencil 壓力感應、5 種筆色、粗細、螢光筆、橡皮擦、復原；預設「僅 Pencil 書寫」，手指照常捲動 |
| 判解函釋 | 大法官解釋 16 則（全國法規資料庫原文）、最高法院判決 36 則、勞動部（勞委會）及內政部函釋 7 則，依條號歸類；可自行新增判決／函釋、對每則加個人註記 |
| 新舊條文對照 | 「修法沿革」列出 73 年制定以來 24 次公布的修正條文對照表；每條的「沿革對照」可任選兩個版本比較，新增文字綠底、刪除文字紅色刪除線 |
| 搜尋 | 同時搜尋條文、我的註記、判解函釋；輸入條號（24、9-1、9之1、第32條之1）按 Enter 直接跳轉 |
| 書籤 | 條文右上角星號；「我的筆記」彙整書籤、註記、螢光、手寫與自訂判解 |
| 外觀 | 字級、黑體／明體、淺色／護眼／深色、項次標示（Ⅰ Ⅱ／① ②） |
| 備份 | 「設定」→ 匯出備份（JSON，可存到「檔案」或 iCloud Drive）、匯入（取代或合併） |

## 在 iPad 上使用

1. 把本 repo 部署為靜態網站（擇一）：
   - **GitHub Pages**：Settings → Pages → Source 選 `Deploy from a branch`，選擇分支與 `/ (root)`。
   - 或任何靜態主機（Netlify、Cloudflare Pages、自架伺服器）。全部是靜態檔，不需後端。
2. 用 iPad Safari 開啟網址 → 分享 → **加入主畫面**。之後從主畫面開啟即為全螢幕 App，離線也能用。
3. 個人資料只存在該裝置瀏覽器（IndexedDB）。**請定期在「設定」匯出備份**；換裝置時匯入即可。

> 本機測試：`python3 -m http.server` 後開啟 `http://localhost:8000/`。

## 資料來源與正確性

- 現行條文、歷次修正版本條文、大法官解釋：法務部「全國法規資料庫」（law.moj.gov.tw）。
- 判決：以司法院裁判書系統（judgment.judicial.gov.tw）近年勞動判決為樣本，統計被引用最多的最高法院判決，要旨文字摘錄自**實際引用該判決的法院判決原文**，並附上引用判決連結。
- 函釋：同樣取自法院判決中引用的主管機關函號與內容。
- 團體協約法典：條文、歷次版本、工會法等相關條文取自全國法規資料庫；判決要旨為**最高法院、最高行政法院判決理由之原文摘錄**（以 `tools/cba_mine.py`、`tools/cba_fetch.py` 自裁判書系統取得全文，再由 `tools/build_cba_cases.py` 依起訖文字逐字擷取）；若摘錄的是被上級審維持的原審見解，會在出處註明。裁決與函釋為判決中引述之內容。
- 本工具僅供學習與參考，正式引用請查核原文。

## 專案結構

```
index.html, app.css, app.js   前端（無相依套件；兩部法典共用 app.js / app.css）
cba/                          團體協約法典（index.html、cba-data.js、sw.js、manifest、icons）
data/cba/raw/                 團體協約法官方原始資料、相關法律條文、裁判書擷取結果
data/cba/curated/             97 年條次對應、詞句連結、相關法條、編按（annot.json）；判決裁決函釋（cases.json）
sw.js, manifest.webmanifest   PWA 離線快取與安裝
data/lsa-data.js              建置產生的資料檔（請勿手改）
data/raw/                     官方原始資料（各版本條文、解釋、條號對應）
data/curated/cases.json       判決、函釋資料（可自行增修後重新建置）
tools/                        抓取、解析、建置腳本
```

### 重新建置資料

```bash
# 1. 解析全國法規資料庫各版本 HTML（LawAll.aspx / LawOldVer.aspx?lnndate=YYYYMMDD）
python3 tools/parse_moj.py data/raw/versions.json path/to/ver/*.html
# 2. 解析大法官解釋頁（ExContent.aspx）
python3 tools/parse_ex.py data/raw/interp.json path/to/ex/*.html
# 3. 產生 data/lsa-data.js
python3 tools/build_data.py
```

修法後只要下載新版 `LawAll.aspx` 存成 `YYYYMMDD.html`，連同舊版一起重跑步驟 1、3（並在 `data/raw/meta.json` 的 `histories` 補上沿革文字）。

### 重新建置團體協約法典資料

```bash
python3 -I tools/build_cba_cases.py   # 由 data/cba/raw/fetched.json 逐字擷取判決要旨 → data/cba/curated/cases.json
python3 -I tools/build_cba.py         # → cba/cba-data.js
python3 tools/make_icons.py cba       # 圖示
python3 -I tools/build_artifact.py    # Artifact 版 dist/artifact.html、dist/cba-artifact.html
```

詞句連結、相關法條、編按都在 `data/cba/curated/annot.json`，可自行增修後重跑 `build_cba.py`（找不到的詞句或條文會直接報錯）。
